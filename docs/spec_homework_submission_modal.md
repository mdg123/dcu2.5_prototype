## 1. 목적 / 배경

### 1.1 사용자 지적
> "학생 과제 제출 내용을 확인하는 레이어 팝업이 너무 구린데?"

### 1.2 현행(AS-IS) 모달 구조 분석 (`#submissionDetailModal`)
- `width:90vw; height:90vh; max-height:90vh` 고정 — 어떤 길이의 텍스트가 들어와도 90vh 차지.
- 본문은 단일 `<div>` 한 덩어리 (제출 내용만 단순 텍스트 출력).
- 첨부파일은 푸터의 "첨부파일 열기" 버튼 1개로 축소 — 새 탭으로 강제 이탈.
- 채점은 모달 외부의 표 행에서만 가능 — 모달 닫고 → 행 찾고 → 점수 입력.
- 피드백 채팅은 별도 모달 `#feedbackModal` (560px) — 제출 내용을 못 본 채로 작성.
- 학생 컨텍스트는 헤더 `display_name` 텍스트 한 줄 — 번호·재제출·마감 대비 정보 없음.
- 학생 순회(다음 학생) 동선 없음 — 30명 채점 시 30회 모달 재오픈.

### 1.3 교사 테스터(teacher1) 발견 P1~P5

| 코드 | 문제 | 사용자 영향 |
|------|------|-------------|
| **P1** | 90vh 고정 → 단문 1줄 제출도 거대 빈 공간 95% | 컨텐츠 대비 모달이 과대 — 시각적 피로, 위계 붕괴 |
| **P2** | 모달 내부 채점 불가 — 닫고 표에서 채점 | 클릭 1회 → 4회로 비효율 (열기→닫기→입력→저장) |
| **P3** | 피드백이 별도 모달로 분리 | 제출 내용을 보면서 피드백을 작성할 수 없음 → 정확한 피드백 불가 |
| **P4** | 학생 순회 흐름 없음 | 30명 채점 시 모달 30회 재오픈 — 반복 클릭 부담 |
| **P5** | 학생 컨텍스트 최소화 | 이름만 있고 번호·재제출·마감 대비·학급 평균 없음 — 형평성 채점 어려움 |

### 1.4 목표 (TO-BE)
- **한 화면 채점**: 모달 안에서 내용 보기 → 점수 입력 → 피드백 작성 → 저장 → 다음 학생.
- **콘텐츠 적응형 크기**: 단문 / 통합 / 이미지 첨부 3단계 분기.
- **학생 순회**: ◀ 이전 / 다음 ▶ 버튼 + 키보드 ←/→ + "3/8 채점" 진행 바.
- **풍부한 컨텍스트**: 아바타·번호·정시/지각·재제출·학급 평균.
- **모바일 우선**: <768px에서 Bottom Sheet 패턴.

### 1.5 적용 표준
- **GNB 충돌 방지**: 모달 z-index ≥ 10000 (현행 11000 유지).
- **닫기 버튼 vs 배지 겹침 금지**: 우상단 40px 무배지 영역.
- **공통 UI 스케일** 적용: body 17 / h1 28~30 / h3 19~20 / button 16 / badge 13.
- **사용자 5원칙**: 진입경로·위치피드백·복귀동선·빈/오류상태·평이한 한국어.

## 2. 사용자 시나리오 (8단계)

### 2.1 핵심 페르소나
- **김교사** (3학년 1반 담임, 28명 학급, 6교시 종료 후 채점)
- **목표**: "수학 문제 풀이 과정 설명하기" 과제 28건 35분 안에 채점·피드백 완료

### 2.2 8단계 흐름

| 단계 | 사용자 행동 | 시스템 응답 | 사용자 5원칙 매핑 |
|------|-------------|-------------|--------------------|
| ① 진입 | 과제 상세 페이지 → 제출 현황 표에서 "박학생 4번 제출" 행 클릭 | 모달 열림. 좌측: 제출 내용 / 우측: 채점·피드백 | (a) 진입 경로 — 표 행 자체가 클릭 가능, 호버 강조 |
| ② 컨텍스트 인식 | 헤더에서 "박학생(4번) · 정시 제출 · 마감 -2일 · 1/28명 채점됨" 확인 | 진행 바 표시 | (b) 위치 피드백 — 28명 중 1번째라는 위치 즉시 인식 |
| ③ 내용 정독 | 좌측 패널에서 제출 글 + 첨부 사진 인라인 확인 | 이미지 썸네일 클릭 시 라이트박스 확대 | — |
| ④ 점수 입력 | 우측 점수 입력란에 "85" 입력 → 학급 평균 78점·만점 100점 표기 | 점수 박스 테두리가 파란색 활성화 | (b) 위치 피드백 — 평균 대비 위치 시각화 |
| ⑤ 피드백 작성 | 우측 채팅창에 "풀이 과정이 명확합니다. 다만 단위 표기를…" 입력 → 전송 | 채팅 버블이 즉시 추가, 토스트 "피드백 전송됨" | (d) 빈/오류 상태 — 빈 채팅 시 "첫 피드백을 남겨보세요" |
| ⑥ 저장 | "채점 저장 후 다음 ▶" 버튼 클릭 (또는 Ctrl+Enter) | 점수 저장 → 토스트 "85점 저장 · 박학생→이학생" → 자동으로 다음 학생 모달로 전환 | — |
| ⑦ 순회 | 모달 헤더 ◀ 이전 / 다음 ▶ 또는 키보드 ←/→ | 진행 바 "2/28명" 갱신 | (b) 위치 피드백 |
| ⑧ 종료 | 28번째 학생 채점 후 "닫기" 또는 ESC | 모달 닫힘. 표가 갱신 상태로 남음 | (c) 복귀 동선 — ESC·닫기 버튼·표로 즉시 복귀 |

### 2.3 사용자 5원칙 적용 결과
- (a) 진입 경로: 표 행 클릭 + 호버 시 "자세히 채점하기" 툴팁
- (b) 위치 피드백: 진행 바 + 학급 평균 + 정시/지각 칩 즉시 시각화
- (c) 복귀 동선: ESC, 우상단 ×, "닫기" 버튼, 외부 영역 클릭(데스크톱만) — 4가지 경로
- (d) 빈/오류 상태: 미제출은 "이 학생은 아직 제출하지 않았습니다" 빈 상태 카드. 첨부 없으면 "첨부 없음" 회색 카드. 채점 저장 실패 시 토스트
- (e) 평이한 한국어: "채점하기" / "다음 학생" / "정시 제출" / "지각 N일" — 한자어 최소화

### 8.2 추가 데이터 (백엔드 응답 확장 권장 — 옵션)

다음은 모달의 풍부한 컨텍스트를 위한 **권장** 추가 필드. 누락 시 모달은 안전한 기본값으로 동작.

| `homework.class_avg_score` | 과제 메타 | 학급 평균 점수 | 막대 평균 마커 미표시 |

### 8.3 학생 순회 — 클라이언트 캐싱 (백엔드 변경 없이)

이미 `GET /api/homework/:classId/:homeworkId` 응답에 모든 `submissions` 배열이 포함됨. 모달 진입 시 `window._allSubmissions`에 저장되어 있음 (현행 코드 유지).

```js
// 순회 로직
let currentIndex = 0;
function navigateSubmission(direction) {
  const subs = window._allSubmissions || [];
  const next = currentIndex + direction;
  if (next < 0 || next >= subs.length) return; // 끝 도달
  currentIndex = next;
  renderSubmissionDetail(subs[currentIndex]);
  document.getElementById('scoreInput').focus();
}
// 키보드 바인딩
document.addEventListener('keydown', (e) => {
  if (!isModalOpen()) return;
  if (e.target.matches('input, textarea')) return;
  if (e.key === 'ArrowLeft') navigateSubmission(-1);
  if (e.key === 'ArrowRight') navigateSubmission(1);
  if (e.key === 'Escape') closeModal();
});
```

```js
  const len = (submission.content || '').length;
  const hasImage = submission.attachments?.some(a => /\.(png|jpe?g|gif|webp)$/i.test(a.url));
  const hasAttach = (submission.attachments?.length || 0) > 0;

  if (hasImage || len > 1500) return 'rich';      // 1280px / 85vh
  if (len <= 200 && !hasAttach)  return 'short';  // 680px / auto
  return 'standard';                               // 1080px / auto
}
```
