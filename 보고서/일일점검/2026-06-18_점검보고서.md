## 발견 버그

### BUG-20260618-01

- **우선순위**: P1 High
- **시나리오**: S01
- **모듈**: 인증
- **제목**: 세션 쿠키 Max-Age 미설정
- **재현 단계**:
  1. `POST /api/auth/login` 호출
  2. 응답 헤더 `Set-Cookie` 확인
  3. `Max-Age` 속성 누락
- **기대 결과**: `Max-Age=604800` (7일)
- **실제 결과**: Max-Age 속성 없음 (브라우저 종료 시 세션 소멸)
- **첨부**: HTTP 응답 발췌
  ```
  Set-Cookie: connect.sid=...; Path=/; HttpOnly
  (Max-Age 없음)
  ```
- **추정 원인**: `server.js` 세션 설정에서 `cookie.maxAge` 미지정
- **영향 범위**: 모든 사용자 — 브라우저 재시작 시 재로그인 필요
- **권장 처리**: `server.js` session 설정에 `cookie: { maxAge: 604800000 }` 추가
