## 발견 버그

### BUG-20260628-01

- **우선순위**: P1 High
- **시나리오**: S01
- **모듈**: 인증
- **제목**: Set-Cookie 응답에 Max-Age 필드 누락
- **재현 단계**:
  1. POST /api/auth/login 성공
  2. 응답 헤더 Set-Cookie 확인
  3. Max-Age 필드 존재 확인
- **기대 결과**: `Set-Cookie: connect.sid=...; Max-Age=604800; ...`
- **실제 결과**: `Set-Cookie: connect.sid=...; Expires=Sun, 05 Jul 2026 00:34:41 GMT; HttpOnly; SameSite=Lax` (Max-Age 누락)
- **첨부**:
  ```
  Set-Cookie: connect.sid=s%3A...; Path=/; Expires=Sun, 05 Jul 2026 00:34:41 GMT; HttpOnly; SameSite=Lax
  ```
- **추정 원인**: express-session 설정에서 `maxAge` 대신 `expires` 절대 시각만 설정
- **영향 범위**: 일부 구형 브라우저에서 세션 쿠키 7일 유지 보장 불가
- **권장 처리**: server.js session 설정에 `cookie.maxAge: 7 * 24 * 3600 * 1000` 추가

### BUG-20260628-02

- **우선순위**: P2 Medium
- **시나리오**: S04
- **모듈**: 채움클래스 / 게시판
- **제목**: 두 번째 갤러리 게시글 생성 시 approval_status=approved로 초기화
- **재현 단계**:
  1. S03에서 갤러리 글(id=7) 생성 → pending
  2. teacher1이 승인 (approved)
  3. student1이 두 번째 갤러리 글(id=8) 생성
  4. 응답에 approval_status=approved 확인
