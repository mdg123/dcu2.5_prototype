- **우선순위**: P1 High
- **시나리오**: S01
- **모듈**: 인증
- **제목**: 세션 쿠키 Max-Age 속성 누락
- **재현 단계**:
  1. `POST /api/auth/login` 호출
  2. 응답 헤더 Set-Cookie 확인
- **기대 결과**: `Set-Cookie: connect.sid=...; Max-Age=604800; ...`
- **실제 결과**: `Set-Cookie: connect.sid=...; Expires=Mon, 22 Jun 2026 ...; HttpOnly; SameSite=Lax` (Max-Age 속성 없음)
- **첨부**:
  - HTTP 응답 발췌: `Set-Cookie: connect.sid=s%3A...; Path=/; Expires=Mon, 22 Jun 2026 00:34:15 GMT; HttpOnly; SameSite=Lax`
- **추정 원인**: `express-session` 설정에서 `cookie.maxAge` 미설정, `cookie.expires`만 설정된 것으로 추정
- **영향 범위**: 모든 사용자의 세션 지속성 (Expires는 동작하나 Max-Age 누락은 일부 브라우저/프록시에서 동작 차이 발생 가능)
- **권장 처리**: `server.js` 세션 설정에서 `cookie: { maxAge: 604800000 }` 추가

## 관찰 메모

1. **DB 영속성 이슈**: CCR 환경의 매회 fresh clone으로 DB가 초기화됨. S07에서 배포한 콘텐츠는 오늘 실행에서 초기화됨. `db/schema.js` 시드에 video/quiz 타입 콘텐츠를 포함시켜야 S07/S08 연계 시나리오가 정상 동작.

2. **gallery_events FK 실패**: 서버 기동 시 매번 `[DB] gallery_events 시드 실패: FOREIGN KEY constraint failed` 발생. 3일 이상 지속. 갤러리 이벤트 시드 데이터의 외래 키 참조 대상(사용자 또는 갤러리 항목)이 없는 상태.

3. **응답 성능**: LRS API 17ms, 서비스별 13ms — 모두 GET 1500ms 임계값 이하 ✅.

4. **LRS 과목별 통계 빈 배열**: `by-subject`에서 lessonStats/homeworkStats/examStats 모두 빈 배열. S07 배포 0건으로 자습 과목 집계 없음. 클래스 콘텐츠에 subject 메타 미설정.
