## 3. 발견 버그

### BUG-20260609-01

- **우선순위**: P1 High
- **시나리오**: S01
- **모듈**: 인증
- **제목**: Set-Cookie에 Max-Age 헤더 누락
- **재현 단계**:
  1. admin 계정으로 `POST /api/auth/login` 호출
  2. 응답 헤더 확인: `Set-Cookie: connect.sid=...; Path=/; Expires=...; HttpOnly; SameSite=Lax`
  3. `Max-Age` 속성 없음
- **기대 결과**: `Set-Cookie: connect.sid=...; Max-Age=604800; ...`
- **실제 결과**: `Expires=Tue, 16 Jun 2026 ...` 만 있고 `Max-Age` 없음
- **HTTP 응답 발췌**:
  ```
  Set-Cookie: connect.sid=...; Path=/; Expires=Tue, 16 Jun 2026 00:34:58 GMT; HttpOnly; SameSite=Lax
  ```
- **추정 원인**: express-session 설정에서 `maxAge` 대신 `expires` 만 지정되었거나, connect-sqlite3가 날짜 객체로만 변환하는 경우. `server.js`의 session 설정 확인 필요
- **영향 범위**: 전 사용자. 일부 오래된 브라우저는 Expires만 있는 쿠키를 세션 쿠키로 잘못 처리할 수 있음
- **권장 처리**: `server.js` express-session 설정에 `cookie: { maxAge: 604800000 }` (밀리초 단위) 명시 추가
