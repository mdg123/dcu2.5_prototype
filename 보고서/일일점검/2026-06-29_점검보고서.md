## 3. 버그 리포트

### BUG-20260629-01 [P1] 세션 쿠키 Max-Age 누락

- **시나리오:** S01
- **현상:** 로그인 응답 `Set-Cookie` 헤더에 `Max-Age` 또는 `Expires` 속성 없음
- **영향:** 브라우저 재시작 시 세션 쿠키 삭제 → 자동 로그인 불가, 사용자 재인증 필요
- **재현:** POST /api/auth/login → Set-Cookie 헤더 확인
- **예상 수정:** `express-session` 설정에 `cookie.maxAge` 또는 `cookie.expires` 추가

---

### BUG-20260629-02 [P1] daily-learning bulk-distribute 배포 0개

- **시나리오:** S07
- **현상:** `POST /api/admin/daily-learning/bulk-distribute` 호출 시 `{"created":0}` 반환
- **영향:** 일별 AI 학습 콘텐츠 자동 배포 기능 미작동 → 학생 학습 데이터 미생성
- **재현:**
  ```bash
  curl -X POST /api/admin/daily-learning/bulk-distribute \
    -d '{"startDate":"2026-06-29","endDate":"2026-06-29","scope":"all"}'
  ```
- **원인 추정:** DB에 승인된 콘텐츠가 있으나 대상 학년·과목 매핑 조건을 충족하는 콘텐츠 부족 (수학 과목 전용 로직)
- **예상 수정:** 콘텐츠 시드 데이터 추가 또는 bulk-distribute 매핑 로직 개선

---

### BUG-20260629-03 [P2] /api/board/:classId/pending 라우팅 충돌 404

- **시나리오:** S04
- **현상:** `GET /api/board/:classId/pending` → 404
- **영향:** 교사가 승인 대기 게시글 목록을 API로 조회 불가
- **재현:** GET /api/board/2/pending (교사 세션)
- **원인:** Express 라우터에서 `/:classId/:postId` 패턴이 `/pending`을 postId로 처리 (라우트 등록 순서 문제)
- **예상 수정:** `/pending` 라우트를 `/:classId/:postId` 라우트보다 먼저 등록

1. **S01 관리자 비밀번호 동기화**: 시나리오 문서 기재 비밀번호(`0000`)와 실제 서버 비밀번호(`1234`) 불일치. 문서 수정 필요.
2. **S02 read 엔드포인트 명시**: `/notice/read` 별도 POST가 없고 GET 조회 시 자동 처리됨을 문서에 명시.
3. **S05 파라미터 표준화**: reflection의 `content`/`text` 혼용, feedback의 `user_id`/`student_id` 혼용 → API 파라미터 통일 및 문서 정정.
4. **S07 시드 데이터**: bulk-distribute 테스트를 위해 학년별 과목별 승인 콘텐츠 최소 시드 데이터 구성 필요.
5. **S08 감독 기능 로드맵**: 시험감독 API 구현 계획 및 ETA를 시나리오에 명시하거나 S08을 미구현 SKIP으로 분류.
6. **S10 경로 오류 수정**: `/api/content` → `/api/contents` 전체 문서 일괄 정정.
7. **S11 결과 경로 수정**: `/results` → `/results-detail` 문서 정정.
8. **S12 파라미터 정정**: `participant_ids` → `targetUserId` (1:1) / `memberIds` (그룹).
9. **S13 학습맵 시드**: 학습맵 노드 시드 데이터 또는 진단 완료 후 자동 생성 로직 구현.
10. **S16 반응형 테스트**: CI 환경에서 Playwright/Puppeteer를 활용한 반응형 자동 스크린샷 추가.
