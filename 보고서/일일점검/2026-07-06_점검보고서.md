## 발견 버그

### BUG-20260706-01

- **우선순위**: P1 High
- **시나리오**: S01
- **모듈**: 인증
- **제목**: 세션 쿠키에 Max-Age 누락
- **재현 단계**:
  1. POST /api/auth/login (admin 또는 임의 계정)
  2. 응답 헤더 Set-Cookie 확인
- **기대 결과**: `Max-Age=604800` (7일) 포함
- **실제 결과**: `Set-Cookie: connect.sid=...; Path=/; Expires=Mon, 13 Jul 2026...; HttpOnly; SameSite=Lax` — `Max-Age` 없음 (Expires 방식만 사용)
- **첨부**:
  - HTTP 응답 발췌:
    ```
    Set-Cookie: connect.sid=...; Path=/; Expires=Mon, 13 Jul 2026 00:39:02 GMT; HttpOnly; SameSite=Lax
    ```
- **추정 원인**: express-session 설정에서 `cookie.maxAge` 미설정 또는 `saveUninitialized`/`resave` 옵션 문제. `server.js` 세션 설정 섹션 확인 필요.
- **영향 범위**: 모든 사용자 — 브라우저마다 Expires 해석이 다를 수 있으며, Strict 환경에서 세션이 기대보다 짧게 유지될 수 있음.
- **권장 처리**: `server.js` 세션 설정에 `cookie: { maxAge: 604800000 }` (ms 단위) 추가.
