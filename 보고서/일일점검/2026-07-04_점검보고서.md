- **우선순위**: P1 High
- **시나리오**: S16
- **모듈**: 스스로채움
- **제목**: 학년별 오늘의 학습 학년 필터 누락(재발)
- **재현 단계**:
  1. student1 (grade=4) 계정으로 로그인
  2. `GET /api/self-learn/daily` 호출
  3. 응답 내 `sets` 배열의 `target_grade` 확인
- **기대 결과**: grade=4(또는 null)인 set만 반환
- **실제 결과**: `target_grade` 값 `[7, 8, 9, 10, 3, 4, 5, 6, 4, 4, null]` — 다른 학년 set 전체 노출
- **첨부**:
  - HTTP 응답 발췌:
    ```json
    { "success": true, "sets": [
      { "target_grade": 7, ... },
      { "target_grade": 8, ... },
      { "target_grade": 9, ... },
      { "target_grade": 10, ... },
      ...
    ] }
    ```
- **추정 원인**: `routes/self-learn.js` 의 daily 조회 쿼리에서 `WHERE target_grade = ?` 조건이 누락되었거나, 사용자 grade 프로필이 null이어서 전체 반환 중
- **영향 범위**: 모든 학생 계정 — 학년 구분 없이 전체 학습 set 노출
- **권장 처리**: `routes/self-learn.js` daily GET 핸들러에서 `req.user.grade`로 필터링 추가, 또는 `users.grade` 컬럼이 null인 경우 학년 선택 강제
