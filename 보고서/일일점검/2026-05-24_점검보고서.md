## 관찰 메모

1. **admin 비밀번호 불일치**: 시나리오 문서는 `admin/0000`이나 실제 서버는 `admin/1234`. `db/schema.js` seedAdmin()을 확인하여 문서와 동기화 필요.
2. **better-sqlite3 Node 버전 호환**: 패키지는 Node v20용으로 빌드됨. 서버는 v22에서 실행. 현재 서버 구동에는 문제 없으나 직접 `node -e` DB 조회 시 Node 버전 경로 지정 필요(`/opt/node22/bin/node`).
3. **preview MCP 미지원 환경**: 이 실행 환경에서 preview MCP 도구가 미등록 상태. HTTP+DB 폴백으로 진행. 스크린샷 수집 0건 (브라우저 기반 UI 검증 불가).
4. **S12 메시지 API 변경**: 시나리오 문서의 `POST /api/message` 대신 실제 API는 `POST /api/message/rooms` + `POST /api/message/rooms/:id/messages` 패턴 사용. 문서 갱신 필요.
5. **LRS 응답 성능**: 모든 LRS API 30ms 이하 응답 — 우수.
