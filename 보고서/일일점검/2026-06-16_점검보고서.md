### BUG-20260616-01

- **우선순위**: P1 High
- **시나리오**: S01
- **모듈**: 인증
- **제목**: 로그인 쿠키 Max-Age 누락 (세션 만료 정책 결함)
- **재현 단계**:
  1. `POST /api/auth/login {username:'admin', password:'1234'}`
  2. 응답 헤더 `set-cookie` 확인
- **기대 결과**: `Set-Cookie: connect.sid=...; Max-Age=604800; ...`
- **실제 결과**: `Max-Age` 필드 없음 — 세션이 브라우저 세션 만료 시 소멸
- **HTTP 응답 발췌**:
  ```
  set-cookie: connect.sid=s%3A...; Path=/; HttpOnly
  (Max-Age 없음)
  ```
- **추정 원인**: `routes/auth.js` 또는 세션 설정에서 `cookie.maxAge` 미설정
- **영향 범위**: 전체 사용자 — 브라우저 재시작 시 재로그인 필요
- **권장 처리**: `express-session` 설정에 `cookie: { maxAge: 604800000 }` 추가
