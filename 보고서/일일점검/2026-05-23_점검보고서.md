## 관찰 메모

1. **admin 비밀번호 불일치**: `db/schema.js` 서버 로그 `관리자 기본 계정 생성 (admin / 1234)` — 시나리오 문서와 다름. 실제 password hash를 서버 로그로만 알 수 있어 onboarding 위험.
2. **notice /confirm 엔드포인트 미구현**: 알림장 `require_confirm` 옵션이 있지만 `/api/notice/:classId/:noticeId/confirm` 라우트 없음. GET으로 읽으면 자동 is_read=1 처리. 알림장 확인 7/10은 별도 UI confirm 버튼이 아닌 GET read 동작으로 달성.
3. **문제집 API camelCase 불일치**: `/api/self-learn/problem-sets/:id/items` 는 `contentId` (camelCase) 요구. 시나리오 문서의 `content_id` (snake_case)로 요청 시 NOT NULL constraint 에러 반환(HTTP 200 body에 success:false). HTTP 상태 코드도 400이 아닌 200 → P2 수준.
4. **일괄 배포 선행조건 누락**: S07 `선행조건: 없음`이지만 실제로 approved contents 없으면 배포 0건. S10 이후에 배포 재시도 필요.
5. **daily_learning_progress 이중 호출 필요**: `complete` 전 `start` 미호출 시 UPDATE 대상 row 없어 progress 미기록.
6. **반응형 테스트 SKIP**: preview MCP 미제공으로 다양한 뷰포트 스크린샷 불가. 가로 스크롤 DOM 측정 불가.
